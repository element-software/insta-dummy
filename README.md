# insta-dummy

A dummy Instagram profile app built with **React Native** + **React Native Web** — identical UI on mobile and browser. Intended as a prop for movies or videos.

## Features

- Instagram-like profile page (top bar, avatar, stats, bio, story highlights, photo grid, bottom tab bar)
- Tap any empty grid cell to pick a photo from your device's library
- Selected photos are stored locally (no server, no database, no API calls)

## Get started

```sh
npm install
```

### Run on web
```sh
npm run web
```

### Run on Android / iOS
```sh
npm run android
npm run ios
```
